# 유니 타임즈 — 가족이 함께 만드는 신문

가족이 함께 기사를 쓰고, 생일·기념일을 챙기고, 사진 앨범과 카드를 만드는 가족신문 웹앱입니다.
외부 패키지 없이 **Node.js만 있으면** 돌아갑니다 (`npm install` 필요 없음). 인터넷에 올릴 때는 Vercel + Neon도 쓸 수 있어요 ([VERCEL.md](VERCEL.md)).

> 이 저장소의 `data-seed.json`은 **예시 가족(가상의 이름)** 자료입니다. 실제 가족 자료는 올리지 않습니다.

## 실행하기

1. Node.js **22.13 이상**을 설치합니다 (https://nodejs.org 의 LTS 버전).
2. 저장소를 받고 폴더에서:
   ```bash
   git clone https://github.com/<내-아이디>/<저장소-이름>.git
   cd <저장소-이름>
   npm start            # 또는 node server.js
   ```
3. 브라우저에서 http://localhost:3000 을 엽니다.
4. 처음 접속하면 **관리자 계정 만들기** 화면이 나옵니다. 그다음 ⚙️ 설정 → 가족 계정에서 가족을 추가하세요.

| 바꾸고 싶은 것 | 방법 |
|---|---|
| 포트 | `PORT=8080 npm start` |
| 자료 저장 위치 | `DATA_DIR=/경로 npm start` (기본: `data/`) |
| 처음 넣을 자료 | `data/seed.json`이 있으면 그것을, 없으면 `data-seed.json`(예시)을 씁니다. 자료가 하나도 없을 때 한 번만 들어갑니다. |

## 기능

| 메뉴 | 내용 |
|---|---|
| 신문 1면 | 톱기사, 한눈에 보기 타일, 다가오는 날(D-day), 오늘의 축하 띠, 최근·많이 읽은 기사, 가족 투표, 오늘의 한마디, 코너, 전체 기사 검색 |
| 편집실 · 기사 작성 | 초안 → 승인 요청 → 검토·승인 → 발행, 코너별 작성 틀, 글·사진 블록 편집, 자동 임시 저장, 휴지통 |
| 캘린더 | 월 달력, 여러 날 일정, 생일(양력·**음력**·윤달, 한국식 나이), 기념일(주년), 일요일/월요일 시작, 일정 눌러 바로 수정, 생일·기념일 모아 보기 |
| 가족 광장 | 가족 투표(여러 개 선택·마감일·보기 더하기·수정·다시 열기), 오늘의 한마디(기분 + 140자) |
| 인물 사전 | 기사 인물 태그·생일로 자동 생성, 사람별 생일·관련 기사·프로필 |
| 우체국 | 편지·생일·기념일·크리스마스카드·연하장, 종류마다 다른 디자인 4종, 사진 첨부, 공개/비공개 |
| 사진관 | 사진 보관함, 앨범 디자인 8종(클래식·매거진·스토리북·콜라주·그리드·폴라로이드·스크랩북·필름) × 종이 4색, A4 인쇄·PDF, 책장 (관리자 전용) |
| 시간표 | 학생별 주간 시간표, 학교 교시 + 방과후 + 학원·활동, 모바일 요일 보기, 인쇄 |
| 이달의 지면 | 한 달 기사를 신문 1면처럼 배치, A4/A3 인쇄·PDF |
| ⚙️ 설정 | 내 정보 · 화면 설정(밝기·글자 크기·1면 구성, 기기마다 기억) · 신문 정보 · 가족 계정 · 자료 관리(현황·백업·휴지통) |

계정(7가지, 위 단계는 아래 단계의 일을 모두 할 수 있음):

| 단계 | 할 수 있는 일 |
|---|---|
| 관리자 | 모든 권한 (가족 계정·신문 정보·사진관·자료 관리) |
| 편집장 | 모든 기사 승인·발행·수정, 휴지통 복원 |
| 시니어기자 | 내 기사 바로 발행, 다른 기자 기사 승인·수정 요청 |
| 평기자 | 기사 작성 + 일정·생일·기념일 등록·수정, 인물 프로필 편집 |
| 수습기자 | 기사 작성·승인 요청, 편지·카드 쓰기, 사진 올리기 |
| 구독자 | 모든 기사 읽기, 댓글, 오늘의 한마디, 가족 투표 올리기·참여, 할 일·행사 준비 함께 보기 |
| 방문자 | 로그인하지 않은 사람 — 발행된 기사 읽기, 응원 반응 (‘가족만 보기’를 켜면 볼 수 없음) |

화면은 데스크탑·태블릿·휴대폰에 맞춰 바뀌고, 어두운 화면과 큰 글씨를 지원합니다.

## 메뉴 구성
메뉴는 네 묶음, 모두 한 단계예요. 같은 메뉴 안의 화면은 위쪽 둥근 탭으로 오가요.
- **신문**: 1면 · 기사(코너별 목록 · 🍳 레시피북 · 🗺 여행 지도) · 지면(이달의 지면 · 📚 합본호)
- **일정**: 일정(오늘 · 달력 월간/주간 · 생일·기념일) · 시간표(볼 수 있는 가족만) · 할 일(한눈에 · 집안일 당번 · 가족회의 · 버킷리스트)
- **가족**: 가족 광장(투표 · 한마디) · 가족 앨범(인물 · 성장 기록 · 가족 연표) · 우체국(편지·카드 · 💌 타임캡슐) · 사진관(관리자만)
- **편집국**(기자 이상): 편집실(쓰기 · 검토 · 발행) · 기자단(배지 · 시상식)
- 위쪽: 🔍 검색 · 🔔 알림 · ⚙️ 화면 설정(누르면 화면 밝기 · 글자 크기 · 움직임 줄이기 팝업) · ✏️ 기사 쓰기 · 내 계정.
- 휴대폰은 아래 탭(1면 · 기사 · 일정 · 가족 · 전체)으로 움직여요. 일정 화면은 ‘보장설계 도우미’의 업무 › 일정처럼 위쪽 가로 메뉴(오늘 · 달력 · 생일·기념일)와 제목 한 줄, 둥근 상자로 정리했어요.

## 알림
위쪽 🔔에 승인 요청 · 수정 요청 · 승인/발행 · 새 댓글 · 새 기사 · 새 투표 · 오늘/내일 생일·기념일이 쌓여요.
⚙️ 설정 → 내 정보 → 알림에서 **브라우저 알림**을 켜면 사이트 창이 열려 있을 때 휴대폰·컴퓨터 알림으로도 떠요.

## 기록·참여 기능
- **기록과 살림**: 가족 연표·성장 기록(가족 앨범), 레시피북·여행 지도(기사, Leaflet + OpenStreetMap), 집안일 당번(매주 월요일 🔔)·가족회의·버킷리스트(할 일), 기자단(배지 9개). 예전 `#/house` 주소는 새 자리로 넘어가요.
- **말로 쓰기 · 소리로 듣기**: 브라우저 음성 인식(한국어)과 읽어 주기. 서버 비용 없음.
- **이번 주 취재 질문**(1면), **그림 일기** 코너, **💌 타임캡슐 편지**(여는 날까지 봉인, 그날 🔔), **연말 시상식**(합본호 + ‘올해의 기사’ 가족 투표).
- 지도 라이브러리 Leaflet 1.9.4(BSD-2)는 `public/vendor/leaflet/`에 들어 있어요. 지도 그림(타일)과 장소 검색은 OpenStreetMap을 인터넷으로 씁니다.

## 새로 더한 기능
- **자동 백업**: 서버가 켜져 있으면 매일 새벽 3시 무렵 `data/backups/`에 DB 사본(`ytimes-날짜.db`)을 만들고 새 사진도 복사해요. 최근 14일치만 남겨요. ⚙️ 설정 → 자료 관리에서 ‘지금 백업’도 할 수 있어요. 끄려면 `YT_NO_BACKUP=1`.
  - 되돌리기: 서버를 끄고 `data/backups/ytimes-날짜.db`를 `data/ytimes.db`로 복사 → 서버 켜기 (사진은 `data/backups/uploads` → `data/uploads`).
- **앱으로 설치**(서비스 워커 `public/sw.js`): 홈 화면 설치, 빠른 재방문, 인터넷이 끊겨도 마지막으로 본 신문 보기. HTTPS 또는 이 컴퓨터(localhost)에서만 동작해요.
- **반복 일정**: 매주·격주·매월(날짜/N번째 요일)·매년 + 끝나는 날. **하루 전 알림**은 일정마다 켜고 끌 수 있어요.
- **월호 마감 알림**: 매달 마지막 3일, 기자 이상에게 남은 초안·승인 대기 수를 알려줘요.
- **함께 쓴 기자**(공동 바이라인)와 **댓글 답글**.
- **N년 전 오늘**(1면), **기사가 적은 달은 가족 투표·한마디로 지면 채우기**, **연간 합본호**(`#/print-year/연도`).
- **사진관 자동 앨범**: 발행된 기사 사진을 달마다 모아 한 번에 앨범으로.
- **공유 미리보기**: `/a/기사ID` 주소로 공유하면 카카오톡·문자에 제목·요약·사진 카드가 보여요(외부에서 접속 가능한 주소일 때).

시놀로지 등 NAS에서 도커로 24시간 돌리는 방법은 **[NAS.md](NAS.md)** 를 보세요. (`Dockerfile`, `docker-compose.yml` 포함)

## 자료와 백업

- 글·일정·설정: `data/ytimes.db` (SQLite, Node 내장 `node:sqlite`)
- 사진 원본: `data/uploads/` (목록용 작은 미리보기 `*_t.jpg`도 함께 저장)
- `data/` 폴더는 **깃에 올라가지 않습니다** (`.gitignore`). 서버를 끈 뒤 `data/` 폴더를 통째로 복사하면 백업이 됩니다.
- ⚙️ 설정 → 자료 관리에서 JSON 백업 파일도 받을 수 있습니다.

## 가족이 함께 쓰려면 (배포)

- **집 컴퓨터/NAS**에서 실행하고 Tailscale 같은 VPN 또는 Cloudflare Tunnel로 접속
- **클라우드**(Render, Railway, Fly.io 등) — `data/`가 지워지지 않도록 영구 디스크(volume)를 꼭 연결하세요.
- 외부에 공개할 때는 HTTPS를 사용하세요.

- **Vercel + Neon**(서버 없이 인터넷에 올리기): 글·일정은 Neon Postgres, 사진·목소리는 Vercel Blob에 저장해요. 방법은 **[VERCEL.md](VERCEL.md)** 를 보세요. (이때만 `pg`·`@vercel/blob` 패키지를 Vercel이 자동으로 설치해요)

