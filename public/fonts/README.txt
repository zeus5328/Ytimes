PyeongChangPeace (평창평화체) Bold — 평창군 무료 글꼴 (제호에만 사용)

빠르게 열리도록 화면에서는 -core(자주 쓰는 한글 2,350자·영문·기호)와 -ext(나머지 글자) 파일을 씁니다.
이름에 -core/-ext가 없는 원본 글꼴 파일은 다시 나눌 때를 위해 남겨 둔 것이에요(화면에서는 쓰지 않음).

사파리(아이폰·맥)에서도 잘 보이도록 조각마다 woff2와 woff 두 가지를 두었어요. woff2를 못 읽으면 브라우저가 woff를 받아 씁니다.
조각 파일은 원본의 이름·글꼴 정보를 그대로 남기고, 조각마다 고유한 이름을 붙여 만들었어요.
